# UHA v0.1.0-rc.2 — Public Release Polish

`v0.1.0-rc.2` is a source prerelease focused on public-repository cleanup,
portability, documentation clarity, and reproducible offline validation.

## Highlights

- Removed validation-machine-specific runtime paths.
- Improved UE Python Remote Execution discovery and portability.
- Improved diagnostic and live-validation tooling.
- Split third-party notices from the MIT license.
- GitHub now correctly recognizes the repository as MIT-licensed.
- Added `docs/STATUS.md` as the authoritative release-status document.
- Clarified the current scope of UAH and legacy ControlOverlay.
- Improved README structure, navigation, project positioning, and badges.
- Added Windows / Python 3.12 GitHub Actions CI.
- Added repository-wide compile checks and offline regression tests.
- Fixed UTF-8 handling on Windows CI runners.
- Renamed the public repository to `UnrealHybridAgent` and updated repository links.

## Validation

The `main` branch at release time passed the public offline CI suite on
Windows / Python 3.12.

Live validation requiring a real Unreal Editor, physical input, GUI
interaction, Human Override, or external MCP services remains outside
normal CI and is documented separately.

## Release Scope

This remains a source prerelease.

The following remain deferred:

- UAH desktop HUD
- standalone UAH entry points
- legacy ControlOverlay
- production-grade stability
- cross-machine / cross-UE-version guarantees
