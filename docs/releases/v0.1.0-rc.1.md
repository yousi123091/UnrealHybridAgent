# UHA v0.1.0-rc.1 — Unreal Engine 场景自动化预览

UHA 让 AI Agent 在 Unreal Engine 中完成场景查询、编辑、保存与结果验证。本次预发布带来从任务规划、执行通道选择到独立结果核验的一条完整工作流程。

## 主要能力

- **场景查询与观察**：查找 Actor、读取 transform / 标签 / 边界信息，并跟踪指定对象的变化。
- **多步任务执行**：将已支持的自然语言或参数任务拆成步骤，完成查找、检查、移动、复查与保存。
- **批量编辑与恢复**：记录变更前状态，执行批量操作，并在恢复后读回确认。
- **混合执行通道**：接入 Unreal MCP、UE Python 与桌面操作，结合能力和健康状态选择适用路径。
- **独立结果验证**：用实际场景状态核对操作结果，识别部分失败和证据不足。
- **人工接管与执行追踪**：保留独立安全提示、输入许可检查、紧急停止，以及路由、验证和恢复记录。

## 可以体验的流程

查找一个 Actor → 检查当前位置 → 按计划移动 → 重新读取确认 → 保存关卡。

也可以针对一组对象进行批量观察、编辑与恢复，或检查后端健康状态、分析执行记录。

## 开始使用

下载本版本源码，按 README 在 Windows / Python 3.12 环境安装依赖，并填写自己的 UE 工程和外部服务配置。建议先在验证工程中查看计划，再执行编辑。
